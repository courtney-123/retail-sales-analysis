# project 1: Retail Sales Data Standardization & Revenue Grouping

## Overview 
Developed a Python-based data cleaning and aggregation script to handle messy, unformatted text data from regional retail sales records. The project automates the processing of inconsistent string data and outputs clear, business-ready revenue insights. 

## Key Skills Demonstrated 
* **String Cleaning:** Whitespace removal and proper capitalization techniques.
* **Data Aggregation:** Multi-variable grouping and summarization using Pandas.
* **Production Automation:** Converting exploratory notebook code into a reusable Python module (`.py`).

## Technical Stack
* **Python 3**
* **Pandas** (Data Aggregation & Wrangling)
